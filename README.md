# KCPH ICD-10 Finder

A bilingual Khmer/English tool for finding ICD-10 codes (96,693 codes from ICD10-Diagnosis_Updated_9). It includes KCPH risk colours, Khmer word search, a code checker, patient code lists, a monthly usage report, and ICD-10 application guides in English and Khmer.

Developed by **Dr. Yeap Kong**, Chief of the Technical Office, Kampong Chhnang Provincial Hospital (KCPH).

- App: https://kcnprhospital-web.github.io/ICD-10/
- Guide (English): https://kcnprhospital-web.github.io/ICD-10/guide-en.html
- Guide (Khmer): https://kcnprhospital-web.github.io/ICD-10/guide-kh.html
