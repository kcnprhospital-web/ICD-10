# KCPH ICD-10 Finder

A bilingual Khmer/English tool for finding ICD-10 codes (96,693 codes from ICD10-Diagnosis_Updated_9), with KCPH risk colours, patient code lists and a monthly usage report.

Developed by **Dr. Yeap Kong**, Chief of the Technical Office, Kampong Chhnang Provincial Hospital (KCPH).

Live app: https://kcnprhospital-web.github.io/ICD-10/
